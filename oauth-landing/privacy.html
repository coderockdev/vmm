Política de privacidade

Última atualização: 29 de setembro de 2026

1. Quem somos

O VMM (Viral Money Machine) é uma ferramenta de produção de conteúdo para YouTube. A aplicação principal corre localmente no computador do utilizador. Este site público existe para documentar o produto e cumprir os requisitos do Google OAuth / YouTube Data API.

2. Que dados usamos

Quando autorizas a ligação ao YouTube através do VMM:

  • Pedimos acesso OAuth aos scopes youtube.upload e youtube para enviar vídeos privados e gerir uploads associados à conta que escolheres.
  • Guardamos um refresh token encriptado no servidor/base de dados do VMM (no teu ambiente), associado ao canal VMM — não no browser.
  • Podemos ler o nome e o ID do canal YouTube ligado (channels.list?mine=true) só para confirmares que é a conta correta.
  • Ficheiros de vídeo, áudio e miniaturas são gerados e, por defeito, ficam no teu computador; o upload para YouTube ou armazenamento na nuvem só acontece quando tu inicias essa ação.

3. O que não fazemos

  • Não vendemos dados pessoais.
  • Não usamos os teus dados do YouTube para publicidade a terceiros.
  • Não publicamos vídeos como públicos automaticamente via API sem a tua ação no fluxo.

4. YouTube API Services

O uso e a transferência para outras apps de informação recebida das APIs do Google cumprem a YouTube API Services Terms of Service, incluindo a YouTube API Services Developer Policies. Podes revogar o acesso a qualquer momento em Google Account → Segurança → Acesso de apps de terceiros ou no VMM com «Desligar» YouTube.

5. Conservação

Tokens OAuth permanecem enquanto a conta estiver ligada no VMM. Ao desligar, o token é apagado da base do VMM. Vídeos já enviados ao YouTube ficam sob as regras da tua conta YouTube.

6. Contacto

Dúvidas sobre privacidade: contacta o administrador do projeto Google Cloud / canal YouTube associado (ex.: conta usada para o OAuth do Amor Amor).
